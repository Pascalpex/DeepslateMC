# DeepslateMC
### A fork of [Leaf](https://github.com/Winds-Studio/Leaf) that adds neat functionalities
<br/>
</div>

## Information
This fork aims to add useful little functionalities to replace plugins that many servers use, like spawn commands, tablist decoration, a bossbar or the ability to clear the chat.
<br>
All messages are customizable in a separate file. The default ones are in English and you can find translated ones [here](https://deepslatemc.de/translations/).
<br>
You can find a full list of features, commands, permissions, config options and other information in the [docs](https://deepslatemc.de/docs/).
## Building
```
./gradlew applyPatches
./gradlew createPaperclipJar
```
